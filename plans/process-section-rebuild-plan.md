# ProcessSection v2 — Linear Client Journey

## Context

v1 (zigzag editorial layout) had copy that overlapped ValuePropositionB, steps that felt disconnected, and unobjective messaging. This v2 redesigns the section as a linear vertical timeline showing the literal client journey from first contact to running automation.

## Copy

**Heading:** "Como trabalhamos"
**Subtitle:** "Da primeira conversa ao sistema rodando — cada etapa do nosso processo, com prazos reais."

| # | Title | Description | Duration |
|---|-------|-------------|----------|
| 01 | Conversa inicial | What tools, volume, errors — free diagnosis | 30 min (gratuito) |
| 02 | Proposta personalizada | Scope doc with integrations, timeline, price | 2-3 dias uteis |
| 03 | Construcao e testes | Build, connect, test with real data, validate | 1-4 semanas |
| 04 | Ativacao e suporte | Go live, monitor, ongoing maintenance | continuo |

## Layout

Linear vertical timeline — continuous line on left, oversized numbers as nodes, content to the right. All steps left-aligned, connected as one unbroken process.

## Key decisions
- Copy is objective (describes what happens, no selling)
- No overlap with ValuePropositionB
- Step element design kept from v1 (number, rule, title, desc, duration tag)
- useScrollReveal for staggered entrance animations
